Hide Pages for Users

Keep the Odoo interface focused by configuring which form pages (tabs) are visible to selected users. Tailor the interface to different responsibilities and business needs with centrally managed restrictions.

✓ User-focused interface ✓ Configurable restrictions ✓ Backend integration

Module Screenshots & Overview

See the page restriction configuration, the administrator view, and an example of the restricted-user form view.

Key Features

Page Visibility Management

Configure which named notebook pages should be hidden from selected users in supported Odoo forms.

User Access Configuration

Associate page restrictions with user accounts to tailor the interface to their responsibilities.

Administrator Controls

Manage page restriction records from a dedicated backend configuration menu.

Odoo Backend Integration

Use Odoo backend assets and server-side configuration endpoints to supply page visibility settings to the interface.

Why use this module?

  • Help keep the interface relevant to each user's role.
  • Centralize page restriction configuration for administrators.
  • Support different visibility needs across teams.
  • Reduce unnecessary tabs and visual clutter for configured users.

Important Security Note

Hiding a page in the interface does not secure its underlying data or prevent direct URL, RPC, or API access. For sensitive operations, configure and test appropriate server-side access rights, record rules, and model permissions.

Installation & Usage

  1. Copy the module into an Odoo addons directory.
  2. Restart the Odoo service and update the Apps list.
  3. Install the module from the Apps menu.
  4. Open the Page Restrictions configuration menu and create a restriction using the technical name of the target notebook page.
  5. Assign the restriction to the intended users, then open the relevant form as a test user and verify the result.

The exact menu labels and configuration fields depend on the final implementation packaged with the module.
